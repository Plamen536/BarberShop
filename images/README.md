# Снимки

Сложи файловете тук със **същите имена**. Докато някоя липсва, сайтът показва
тъмен placeholder с името на файла, за да се вижда къде отива.

| Файл            | Къде се показва                       | Препоръчителен размер |
| --------------- | ------------------------------------- | --------------------- |
| `hero.jpg`      | Фон на началната (Hero) секция        | 1920×1080, тъмна снимка (върху нея има текст) |
| `about.jpg`     | Секция „За нас“ (вертикална снимка)   | 1000×1250 (4:5)       |
| `gallery-1.jpg` … `gallery-6.jpg` | Галерия (квадратни)  | 1000×1000             |
| `team-1.jpg`    | Първи бръснар (ред 1 в `src/data/team.js`) | 800×1000 (4:5)   |
| `team-2.jpg`    | Втори бръснар                         | 800×1000              |
| `team-3.jpg`    | Трети бръснар                         | 800×1000              |

Съвети:

- Използвай JPG (или WebP) и компресирай до под ~300 KB на снимка.
- За да добавиш още снимки в галерията, добави ред в `src/data/gallery.js`.
- Имената на файловете за екипа са в `src/data/team.js` (поле `image`).
- Alt текстовете (описанията за достъпност) се редактират в същите файлове.
